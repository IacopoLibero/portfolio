## Overview

David La Gelateria is a complete management system developed for an artisanal gelato shop located in Florence, Italy. The system enables the shop owners to manage their product catalog, digital menu displays for in-store monitors, video advertisements (spots), and a customer-facing digital menu with bilingual support. The platform streamlines daily operations and provides an engaging visual experience for customers.

## Key Features

- **Product Catalog Management**: Complete CRUD operations for gelato products with attributes like Km0, Vegan, Slow Food, Bio, and Innovative certifications.
- **Digital Menu Display**: Vertical menu layout designed for in-store monitors, dynamically showing available products organized by category.
- **Video Spot System**: Upload and manage promotional video spots with configurable display intervals and visibility settings.
- **Bilingual Digital Menu**: Customer-facing menu with Italian and English language selection, displaying products with prices and ingredients.
- **Dynamic Font Sizing**: Adjustable font sizes for menu displays to accommodate different screen sizes and viewing distances.
- **Category Management**: Organize products into customizable categories with bilingual names.
- **Secure Authentication**: Login system with "Remember Me" functionality using secure tokens and session management.
- **Responsive Admin Dashboard**: Collapsible sidebar navigation with organized sections for each feature area.

## Technologies Used

- **PHP**: Server-side logic and database interactions with prepared statements for security.
- **MySQL**: Relational database for storing products, categories, users, spots, and menu items.
- **JavaScript**: Dynamic UI interactions, form validation, and AJAX operations.
- **CSS**: Custom styling with responsive design for both admin dashboard and public-facing displays.
- **HTML5**: Semantic markup for accessibility and SEO.
- **Session Management**: Secure authentication with token-based "Remember Me" functionality.

## Challenges and Learnings

The main challenge was creating a system that could be easily used by non-technical staff while maintaining robust security. Implementing the dual-language system for both product names and descriptions required careful database design. The video spot management system needed to handle file uploads securely while providing a smooth playback experience on in-store displays. I learned valuable lessons about building intuitive admin interfaces and optimizing database queries for real-time display updates.

## Outcome

The David La Gelateria management system successfully streamlines the shop's daily operations. Staff can easily update the menu when new flavors are available, manage promotional videos, and maintain accurate product information in both Italian and English. The digital displays provide an engaging customer experience, showcasing the artisanal quality and certifications of each gelato flavor.
