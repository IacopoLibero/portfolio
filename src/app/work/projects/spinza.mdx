## Overview

Spinza is a comprehensive full-stack web application developed for an artisanal pinseria located in the heart of Florence. The project showcases the restaurant's unique identity, combining traditional Italian cuisine with art, music, and a vibrant atmosphere. The website features a complete bilingual experience (Italian/English), dynamic content management, and a powerful admin dashboard for the restaurant owners to manage their menu, events, and business operations.

## Key Features

- **Bilingual Support**: Full internationalization with next-intl, allowing seamless switching between Italian and English languages across all pages.
- **Dynamic Menu Management**: Complete CRUD operations for menu categories and products with image uploads, allergen information, and pricing.
- **Events Management**: Admin panel to create, edit, and manage upcoming events with status tracking (upcoming, ongoing, completed, cancelled).
- **Responsive Design**: Mobile-first approach with custom navigation, optimized for all device sizes.
- **SEO Optimization**: Schema.org structured data, dynamic metadata generation, XML sitemap, and optimized Open Graph tags.
- **Admin Dashboard**: Secure authentication with Supabase Auth, role-based access control, and intuitive content management interface.
- **Contact Integration**: Dynamic contact information management with Google Maps integration.
- **Legal Compliance**: GDPR-compliant cookie consent, privacy policy, and terms of service pages.

## Technologies Used

- **Next.js 14**: App Router with server components for optimal performance and SEO.
- **TypeScript**: Full type safety across the entire codebase.
- **Supabase**: Backend-as-a-Service for authentication, PostgreSQL database, and file storage.
- **next-intl**: Internationalization framework for bilingual content management.
- **CSS Modules**: Scoped styling with custom design system and responsive breakpoints.
- **React Hook Form**: Form validation and management with Yup schema validation.
- **Framer Motion**: Smooth animations and scroll-triggered effects.

## Challenges and Learnings

The main challenge was building a complete full-stack solution that could be easily managed by non-technical restaurant staff. This required creating an intuitive admin interface while maintaining robust security measures. Implementing bilingual support across all dynamic content (menu items, events, blog posts) while keeping the codebase maintainable was another significant challenge. I also learned a lot about optimizing images for performance, implementing proper SEO for local businesses, and creating accessible user interfaces.

## Outcome

The Spinza website successfully serves as the digital home for the pinseria, effectively showcasing their unique offerings and atmosphere. The admin dashboard empowers the restaurant owners to independently manage their content, reducing their dependency on technical support. The SEO optimizations have improved the restaurant's online visibility, and the bilingual support has helped attract both Italian and international customers visiting Florence.
